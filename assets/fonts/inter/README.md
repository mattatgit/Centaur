# Inter 4.1

Unmodified static TrueType fonts from the official [Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), by Rasmus Andersson and the Inter Project Authors. Licensed under the SIL Open Font License 1.1; see [LICENSE.txt](LICENSE.txt).

Only the styles currently used by the interface are bundled: Regular (400), SemiBold (600), and Bold (700). Qt can still fall back to system fonts for characters outside Inter's coverage. These files are embedded in both Centaur and its separate native preview/checker so they work without a system font installation or network access.
