# Inter Tight

Unmodified upright variable TrueType font from Google Fonts, licensed under
SIL Open Font License 1.1. Its variable weight axis supplies Regular (400),
Semibold (600) and Bold (700) without separate files. The licence is bundled
and installed alongside the existing Inter licence.

Pinned Google Fonts commit: `0b58fb370093f9a9f4ff785d94405710b79de67c`.

Source: https://github.com/google/fonts/tree/0b58fb370093f9a9f4ff785d94405710b79de67c/ofl/intertight

`InterTight[wght].ttf` is copied unchanged as `InterTight-Variable.ttf` for a
portable resource filename. No font outlines, naming tables or metrics are modified.

Centaur uses Inter Tight above 12 pt and Inter at 12 pt or smaller. Pixel-based
UI sizes are converted using Qt's font metrics rather than assuming screen DPI.
The default application font remains Inter for small/default controls. Sizes
and weights are unchanged. Both native rendering processes bundle both families;
the starter app declares the same split explicitly.
